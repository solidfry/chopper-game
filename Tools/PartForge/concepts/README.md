# Arcus Aerodyne concept references

Quality and shape references from the owner (28 Nov 2026) for the sleek second chassis line (`partforge/sleek.py`).
The images are third-party art: kept here for reference only, git-ignored, never shipped.

| File | What to take from it |
|---|---|
| `arcus_ref_01.png` | White and black two-tone pod, huge dark wrap-round glass, fan-in-fin tail, low skids. |
| `arcus_ref_02.png` | Silver and red: a hoop band round the cabin, sculpted canopy frame, slim open tail truss. |
| `arcus_ref_03.png` | Long, low, faceted attack hull; stepped tandem canopy; coaxial head; large swept fin. |
| `arcus_ref_04.png` | White pod with a big round fan shroud, pierced side windows, slim skids. |
| `arcus_ref_05.png` | Four coaxial variants: needle nose, long canopy, swept intake hump, fins and ventral fins. |
| `arcus_ref_06.png` | Armoured but sleek: gun pods and engines merged into broad shoulders, wheels. |
| `arcus_ref_07.png` | Dark stealth body, broad swept wings, twin canted tail fins, faceted panels. |
| `arcus_ref_09.png` | Heavy attack heli: dense panel breaks, door frames, chin turret, livery bands, ring fan (top). |
| `arcus_ref_10.png` | Ducted fan / tilt nacelles merged into the hull; orthographic sheets; dense panel definition. |

The owner's notes so far: shapes must look designed and blended, not primitives stuck together (booleans,
fillets, normal transfer); boosters merged into the fuselage; cockpit proportions in line with the hull; no glass
crossing other parts; much more panel definition.
